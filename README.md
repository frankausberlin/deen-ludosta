# 📚 The AI-flavored **De**veloper **En**vironment & **Lu**xurious **Do**main **Sta**ck 

**Deen Ludosta** is more than a developer environment. It is built on a **Trinity Architecture** — a foundational design philosophy that separates infrastructure, cognition, and application. 

This strict separation transforms the system from a mere coding workspace into a generic, domain-independent **Cognitive Operating System**.

## 🌌 The Trinity Architecture: A Cognitive Operating System

### 1️⃣ The Foundation: Base System
The **robust**, **secure**, and highly optimized **Linux** bedrock. It provides raw compute (CUDA), strict security policies (**UFW, SSH hardening**), and package management. It is the physical and secure anchor of the island, running 24/7.

### 2️⃣ The Brain: The AI Stack
**Conrad** is an agent skill (**concierge**), lives in **any harness** and needs access to two mcp servers: **gbrain and lion**. An extensive collection of **other MCP servers** is available to him via the **MCPHub**. Conrad **takes care of the operation** of the base stack and the AI ​​stack; he installs, configures, explains and advises. His name is Conrad and he **solves problems**.


### 3️⃣ The Payload: The Swappable Domain
The top layer is entirely domain-specific. Currently, it houses the **Luxurious Python Stack** for AI software engineering. But because the foundation and the engine are completely agnostic, this layer is infinitely swappable (**Lurusta** Luxus Rust Stack or **Luhasta** Luxus Hacker Stack)


## Quickstart

1. **Install Lion**
> * Carry out the three installation steps described in chapter [Quickstart](https://github.com/frankausberlin/lion#quickstart) in the Lion README.md.

2. **Install Hermes**
> * We use the shlib watch to install hermes with some additional infos for lion.
```shell
# activate watch mode
lion watch start

# write your open router key in exports
echo "yourkey" > ~/.shlib/exports/OPENROUTER_API_KEY
chmod 600 ~/.shlib/exports/OPENROUTER_API_KEY
exec zsh # load key in environment

#.LION: addr.title KiloCode CLI as default harness
```
